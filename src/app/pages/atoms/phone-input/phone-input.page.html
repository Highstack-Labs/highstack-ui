Instalación

Importa el phone input:

El valor es siempre un string en formato E.164 — '+593987654321' — o '' si el campo está vacío. Es lo que se guarda en base de datos y lo que esperan las APIs de mensajería; el país se deriva del prefijo al leerlo. La validación es de longitud y dígitos, no de reglas de operadora: +593000000000 pasa. Para más rigor, valida también en el servidor.

Se puede teclear el número nacional o pegar uno internacional (+34600111222, 0034600111222): al pegar, el país se re-detecta. El agrupado visual se aplica al salir del campo, y los errores de longitud también: nunca mientras se escribe. Cambiar de país conserva los dígitos ya tecleados. Con prefijos compartidos (+1, +7) el valor siempre es correcto, pero un número que llega de fuera sin país elegido se muestra con la bandera del país principal (Estados Unidos, Rusia).
