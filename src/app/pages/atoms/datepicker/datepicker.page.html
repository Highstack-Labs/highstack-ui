Instalación

Importa el datepicker:

El valor es siempre un string ISO 'YYYY-MM-DD' (o '' si no hay fecha), nunca un Date.

Valor: {{ fecha() || '—' }}

Signal Forms

Vincula con [formField] de Angular 22.

Form válido: {{ signalForm().valid() }}

Reactive Forms

Funciona con [formControl] / [(ngModel)] vía ControlValueAccessor.

Valor: {{ reactiveCtrl.value || '—' }}

Propiedades (API Reference)

Prop Tipo Default
value string ISO 'YYYY-MM-DD' (model) ''
label / hint / error / placeholder string ''
size 'sm' | 'md' | 'lg' 'md'
disabled / readonly / required boolean false
locale string 'es-MX'
weekStartsOn number (0 = domingo) del locale
min / max string ISO ''
disabledDates readonly string[] []
dateDisabled (iso: string) => boolean —

El orden al teclear lo define el locale (dd/mm/aaaa en es-MX, mm/dd/aaaa en en-US). Los errores de formato solo aparecen al salir del campo, nunca mientras se escribe.
